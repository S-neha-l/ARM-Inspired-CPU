# ARM-Inspired 32-bit CPU | Verilog HDL

This project implements an ARM-inspired 32-bit single-cycle CPU in Verilog HDL.

## Features
- Supports ADD, SUB, AND, ORR, LDR, STR, and B instructions
- Modular RTL architecture: ALU, Controller, Datapath, Register File
- 16-register (R0–R15) register file with PC support
- NZCV flag generation and conditional execution
- Instruction and data memory models
- SystemVerilog testbench for functional verification

## Tools
- Verilog / SystemVerilog
- Icarus Verilog
- GTKWave
